# Support

Design System Workflow is maintained by [Pankaj Vaghela](https://github.com/pankajvaghela).

Report installation problems, unclear workflow behavior or suggestions through [GitHub Issues](https://github.com/pankajvaghela/design-system-workflow/issues). Include the plugin version, agent host, relevant skill, expected result and observed result. If an editor is involved, name it and describe which operations were available. A small fictional example is preferable to a private design.

Issues are public. Do not post credentials, personal data, private documents or unredacted conversation exports. Support is provided through this repository without a guaranteed response time. Host account, billing, connector permission and service-availability problems should go to the corresponding provider.

Before reporting, consult the [installation instructions](README.md#quick-install-preferred) and [privacy policy](PRIVACY.md). The package provides instructions, not an editor connection or a hosted design service.
